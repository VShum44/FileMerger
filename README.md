# 📄 File Merger

Десктопное приложение для склейки текстовых файлов исходного кода в один файл с метаинформацией.

Удобно для подготовки контекста проекта — например, чтобы передать весь код в AI-ассистент или собрать документацию.

## ✨ Возможности

- **Drag & Drop** — перетащите файлы или целые папки прямо в окно
- **Рекурсивный сбор** — при перетаскивании папки автоматически собирает все поддерживаемые файлы внутри
- **Превью содержимого** — просмотр файла прямо в приложении без открытия редактора
- **Склейка с метаинформацией** — каждый файл сопровождается заголовком (имя, путь, размер, строки, символы, слова)
- **Итоговая статистика** — в конце склеенного файла суммарные данные по всему проекту
- **Поиск по имени** — быстрая фильтрация списка файлов
- **Сортировка** — по имени, расширению, пути, размеру, количеству строк или вручную
- **Ручное упорядочивание** — перемещение файлов вверх/вниз кнопками или горячими клавишами
- **Множественное выделение** — Ctrl+Click для выбора нескольких файлов
- **Контекстное меню** — открыть в проводнике, скопировать путь, удалить
- **Светлая / тёмная тема** — переключение одной кнопкой
- **Защита от дубликатов** — повторно добавленные файлы игнорируются
- **Подтверждение при выходе** — если есть несохранённые файлы
- **Логирование** — журнал работы в папке `logs/`

## 🚀 Сборка и запуск

### Требования

- **JDK 17+** (с jpackage)
- **Gradle 9** (встроен через wrapper)

### Запуск из IDE

```bash
./gradlew run
```

### Сборка fat-JAR

```bash
./gradlew shadowJar
java -jar build/libs/FileMerger.jar
```

### Сборка .exe (Windows)

```bash
./gradlew buildExe
```

Результат: `packaging/output/FileMerger/FileMerger.exe`

Приложение **полностью автономное** — Java не требуется на целевой машине.

### Пересборка после изменений

```bash
./gradlew buildExe
```

Одна команда выполняет полный цикл:
1. Компиляция исходного кода
2. Сборка fat-JAR со всеми зависимостями
3. Упаковка в нативный .exe с встроенной JRE
